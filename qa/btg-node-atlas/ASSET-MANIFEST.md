# Beyond the Glass node-atlas asset manifest

All new node art in this pass was created with the built-in image-generation workflow, visually inspected, and exported as a 768 × 768 RGB WebP. The shared direction is a deep-teal SIP Academy study medallion with a restrained double-brass frame, a clear educational silhouette at small sizes, and no generated text, logos, brands, people, or watermarks.

The application only mounts the active stop, so below-the-fold medallions are not requested until their stop becomes active. The complete `public/beyond-the-glass/nodes` directory is approximately 3.0 MB; the 24 new medallions are each approximately 68–147 KB.
